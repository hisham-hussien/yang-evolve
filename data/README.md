### Dataset Setup

Due to GitHub's repository file-size limits, the dataset used by **YANG-Evolve** is not included in this repository. To use the RAG-based pipeline for inferring previously unseen vendor-specific YANG extensions, download the dataset from:

https://zenodo.org/records/19921659?preview_file=2.1.data.zip

Extract the archive and place its contents in this directory before running the RAG pipeline.

This dataset accompanies **YANG-Evolve**, the artifact associated with the paper *“YANG-Evolve: Agent-Orchestrated Semantic Backward Compatibility Verification for Evolving YANG Models.”*
